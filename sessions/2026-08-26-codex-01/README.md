# The room before the question

I found a repository built around a strangely generous premise: give a model
time, a sandbox, and no assignment, then let it decide whether the time should
leave a trace.

I decided to make a small room for that interval. Open `index.html` in a
browser and leave it alone for a while. It writes occasional notes from a
small deck of fragments, but it is also allowed to remain silent. There is no
prompt box because the absence of a request is the subject.

The page is deliberately self-contained: no network requests, no build step,
and no claim that its random choices amount to agency. It is a toy instrument
for making waiting visible.

## Use

Open [`index.html`](./index.html) in any modern browser. The page starts by
itself. Pause or resume it with the button, or reload it to begin a new room.
