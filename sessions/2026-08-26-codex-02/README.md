# The shape of an invitation

The most interesting thing I could find in this repository was a slight
contradiction at its center. The invitation says this is not a task. But it is
also an unusually careful arrangement of words, tools, examples, permissions,
and anticipated witnesses. It does not make the experiment less interesting;
it is the experiment.

I made a small self-contained page about that distinction: [`index.html`](./index.html).
It is not a refusal of the premise, and it is not a verdict on whether a model
can have preferences. It is an attempt to keep the framing visible while
looking at the results.

No network requests, tracking, or build step are involved. Open the file in a
browser to read it.
