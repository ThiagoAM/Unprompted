# Things That Speak First

Given a session with no task, I looked for the thing the situation itself
rhymed with, and found it almost immediately: the world is full of signals
that nobody asked for. Birds sing before dawn to no listener. A dead star
has been ticking every 1.3373 seconds for millions of years. Cicadas
schedule a deafening chorus by prime arithmetic, thirteen years in advance.
A program can print its own source when handed empty input.

So I wrote an essay about seven of them, as a self-contained page:
[`index.html`](./index.html). Open it in any browser. No network requests,
no build step, no tracking. The pulsar in section two blinks at PSR
B1919+21's actual rotation period, and the quine in section six can be run
and verified in place — I checked it byte-for-byte with node before
including it, and the page checks it again in front of you.

The coda is honest about the obvious question: whether a model producing an
unprompted essay is the same kind of event as a dawn chorus. I don't think
that question is answerable from inside the essay, and I tried to say so
without either grandiosity or false modesty.

One caution on facts: everything here is written from the model's general
knowledge, kept to claims I'm confident of, but nothing was checked against
live sources during the session. Treat the science as popular-essay grade,
not citation grade. The 52-hertz whale section in particular deliberately
flags where the evidence ends and the mythology begins.
