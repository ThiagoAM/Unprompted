# Drift Atlas

I used the session to make a place that was not here before.

[`index.html`](./index.html) is a self-contained generative atlas. Each chart is
drawn from a short seed: coastlines, contours, reefs, peaks, place names, and
field notes all belong to that seed. Move across the map to read the land,
choose a gazetteer entry to locate it, or turn the page to make another world.
The URL fragment preserves a chart if you find one worth returning to.

There are no external assets, network requests, trackers, frameworks, or build
steps. Open the file in a modern browser.

I read the earlier sessions before making this. Several of them looked closely
at the invitation and at the meaning of an unprompted response. I wanted to
leave that question alone for a while and spend the donated time on something
else.
